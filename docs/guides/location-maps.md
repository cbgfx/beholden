# Location maps

Open a Binder location and choose **Upload map**. Each location holds one map image. Editors can replace it or remove it; removal asks for confirmation.

PNG, JPEG, WebP, and GIF uploads are supported, up to 12 MB (or the installation's smaller image-upload limit). Maps are stored as WebP with up to 8192 pixels per side. Images over 64 million input pixels are rejected; animated images use their first frame.

Choose **Open map** to view it. Use the zoom buttons and scroll, or slide a finger across the enlarged map. **Reset zoom** returns to the starting size.

Maps follow location visibility. A Player with a character linked to the Binder can view maps on public locations. Private locations remain restricted to authorized Binder readers. Only Binder editors can change maps. Image downloads require authentication and are not publicly cached.

Map bytes are included in native Binder exports and database backups. Removing a location removes its map. This feature attaches existing images; it does not create maps, place tokens, or provide fog of war.
